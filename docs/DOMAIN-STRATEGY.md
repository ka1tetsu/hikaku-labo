   Vercelのプロジェクトにドメインが追加されていない（または設定途中）状態と考えられます。

## 評価の観点

| 観点 | 考え方 | 比較ラボへの当てはめ |
|---|---|---|
| 信頼（ユーザー・ASP審査） | 日本の利用者には `.co.jp` ＞ `.jp` ＞ `.com` ＞ その他の順で安心感がある傾向。お金・通信の比較（YMYL）では重要 | `.jp` を推奨。`.co.jp` は法人化後の選択肢 |
| SEO | トップレベルドメイン自体は順位要因ではない。`.jp` は日本向けサイトという地域シグナルになる（効果は小さい）。ドメイン名に「hikaku」などのキーワードを入れても順位は上がらない | `.jp` で問題なし。キーワード目的の命名は不要 |
| ブランドの一致 | サイト名とドメインが一致すると、指名検索・口コミ・再訪で有利 | 「比較ラボ」＝ hikaku-labo.jp、「ヒカラボ」＝ hikalabo.jp |
| 混同リスク | 似た名前のサイトがあると、指名検索や被リンクが分散する | 「モノ比較ラボ」「ジャンル別比較ラボ」が稼働中 → 差別化が課題 |
| 覚えやすさ・入力しやすさ | 短い・ハイフンなし・ローマ字の揺れが少ない方がよい | hikalabo（8文字）＞ hikaku-labo（11文字・ハイフンあり） |
| 費用 | `.jp` の更新は年3,000〜4,000円前後、`.com` は年1,500〜3,000円前後が相場（レジストラにより異なる。更新料で比較する） | どちらも負担は小さい。**更新料と自動更新の設定を重視** |
| 防衛取得 | 同名の `.com` を他人に取られるとフィッシングや混同の原因になる | hikalabo を選ぶなら `.jp` と `.com` を両方取得 |

## 推奨シナリオ

**A. hikaku-labo.jp がオーナーの所有だった場合（推奨）**
- そのまま本番ドメインにする。ブランド変更なしで移行コストが最小。
- 防衛用に `hikaku-labo.net` の取得は任意（`.com` は他者が保有）。
- 競合との差別化は、サイトの中身（全ショップ価格比較・通信比較・AIコンシェルジュ）とロゴ・表記の統一で行う。

**B. 所有していなかった場合**
- `hikalabo.jp`（＋防衛で `hikalabo.com`）を取得し、サイト名を「ヒカラボ（比較ラボ）」のように短い呼び名へ寄せる。
- 「比較ラボ」のまま `hikakulabo.net` などにする案は、競合と名前が近いまま弱いTLDになるため非推奨。

**商標**：事業として育てるなら、特許庁のJ-PlatPatで「比較ラボ」「ヒカラボ」の登録状況を確認し、必要に応じて出願を検討（広告・比較情報提供の区分）。判断は弁理士に相談を。

## 移行手順（ドメイン決定後）

1. Vercel の Project → Settings → Domains で新ドメインを追加し、表示されるDNS設定を行う（ネームサーバーがVercelならほぼ自動）。
2. Vercel の環境変数を設定して再デプロイ：
   - `SITE_ORIGIN=https://新ドメイン` … canonical・OGP・構造化データ・サイトマップ・robots.txt のURLをビルド時に置き換え（`scripts/prerender.mjs`）
   - `SITE_URL=https://新ドメイン` … 楽天APIへのリクエストのReferer/Origin（`api/search.js`）
3. **楽天ウェブサービスのアプリ設定**で「許可されたWebサイト」に新ドメインを追加（追加しないと商品検索APIが失敗する）。
4. `hikaku-labo.vercel.app` → 新ドメインへの恒久リダイレクトを設定（Vercelのドメイン設定でリダイレクト指定）。
5. Google Search Console に新ドメインを登録し、旧URLのプロパティから「アドレス変更ツール」を実行。sitemap.xml を送信。
6. **A8.net・楽天アフィリエイト・Amazonアソシエイト・バリューコマース等のサイト登録URLを新ドメインに更新**（未登録サイトからの成果は否認されることがある）。
7. `.github/workflows/production-affiliate-audit.yml` の `PUBLIC_SITE_URL` を新ドメインに変更。
8. レジストラで自動更新・ドメインロック・WHOIS公開代行を有効化し、更新期限をカレンダーに登録。
