# 場所・日程・人数からの空室検索

`/travel/#stay-search` で国内の場所・駅名・宿名、チェックイン、チェックアウト、大人人数を入力して検索します。現時点では大人1〜10名・1室・1〜30泊に対応し、朝食付き・温泉ありで絞り込みできます。子ども・複数室は予約サイトで検索してください。

公式KeywordHotelSearch（20260731）の上位30施設を候補として、VacantHotelSearch（20170426）に同じ日程・人数を渡し、取得したプランを評価順・初泊料金順で比較します。検索上位30施設の範囲であり、楽天の全施設登録・全件横断最安検索を完了したものではありません。

公式仕様で `dailyCharge` は初泊1泊分のみです。`dailyCharge.total` を初泊合計として表示し、人数・泊数で再乗算しません。`hotelMinCharge` を予約料金には使いません。全泊総額・キャンセル期限・現地支払額を推定しません。紹介先はAPIが返した楽天のHTTPS URLのみ使用します。

サーバーの `RAKUTEN_APP_ID` / `RAKUTEN_ACCESS_KEY` と、そのアプリでの `https://vivlica.com/` 利用許可が必要です。既存の本番サーバー設定を再利用し、キーをブラウザに渡しません。認証情報の反映はクラウド環境設定とVercel本番設定でそれぞれ必要です。共有されたExplorerキーはコードやGitへ保存していません。

APIエラー・サイト登録制限・レート制限・通信エラーと「候補に空室がない」を分けます。エラー時は予約サイトへの検索リンクを残し、対応するサイトへ日程・人数を引き継ぎます。楽天の一般検索リンクは場所のみです。検索語・日程・人数は匿名クリック計測には送信しません。提供元の生のエラーや秘密値もブラウザへ返しません。
