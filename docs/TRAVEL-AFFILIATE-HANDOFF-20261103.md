# Approved travel referral handoff and clean QA

## Problem and behavior

The Yahoo Travel quote row and lowest eligible recommendation previously sent users through an ordinary official-homepage link. The approved A8 creative was a separate footer ad. The quote action now renders the supplied banner234 creative verbatim in the Yahoo row; when Yahoo is the eligible recommendation, that single creative appears beside the recommended amount instead. Additional Yahoo rows point to the same creative. The workspace does not duplicate the ad or alter ranking weights. Other providers retain their original targets. The domain-registration and emergency-off gate continues to choose ordinary links when advertising is disabled.

The creative's landing page does not carry the visitor's hotel/date/party, and the wrapper says to set these at the advertiser. No referral URL is extracted, rewritten, or assigned to a new custom button. Creative HTML and pixels remain unchanged. Deliberate ad clicks use the existing enum-only `user-quote` event with sponsored=true, which the revenue report already counts independently from ASP settlements.

## QA traffic isolation

Browser QA and live screenshot capture previously loaded third-party ad images. Automated screenshots can therefore contaminate impression-based reports; this does not establish that any particular publisher-reported count was generated by tests. Both scripts now install the same request isolation before navigating. Actual A8/referral domains and first-party `/api/track` are fulfilled locally; ad images use an explicitly labelled SVG fixture, while referral navigation and tracking receive 204. Normal site APIs/assets still load. No real affiliate click is generated to test tracking.

The isolation applies only to automation scripts, never to production visitors. Unit tests cover exact/subdomain boundaries and prevent forwarding ad or analytics requests. Mobile UI QA checks one creative before and after a Yahoo recommendation, no duplicate ordinary Yahoo primary link, and the sponsored user-quote event with no trip/price fields. It simulates the click behind the local request isolation.

## Measurement limits

Ad impressions are not unique visitors. A single reported click cannot establish a reliable conversion rate or incremental profit. Assess qualified sponsored clicks and completed comparisons, then match actual ASP confirmations and direct costs; do not label browser events as earned commission. No paid traffic was purchased and no publisher account financial data is committed in this change.
