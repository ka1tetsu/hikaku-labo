# 比較ラボ：商品価格比較ワークベンチ
更新：2026-10-31

## 実装したこと
- **厳格な一致候補**：同じJAN（双方に存在する場合）または型番一致の根拠がある出品のみを先に表示。それ以外は「似た商品、未照合」として区別し、アクセサリーの誤一致を防ぐ。ブランド・型番が似ていても色、容量、セット内容、新品・中古は未照合。
- **出品ごとの支払条件**：価格と後日ポイント相当額を区別。送料は「取得元の送料無料」「送料別」「送料未取得」を表示。未取得送料を0円と置かない。
- **検索条件の再絞り込み**：楽天・Yahoo、送料の記載、口コミ評価、価格上限、店名・商品名を検索できる。取得済みの最大80件を絞るため、全店舗の網羅ではない。
- **表示方法**：現金支払価格、ポイント差引後の参考額、口コミ評価、口コミ件数で並べ替え。表示数を増やして候補を調べられる。
- **4件の出品比較**：実際の取得データを並べる。JAN/型番照合の根拠、送料区分、ポイント相当額、レビュー、販売店、ショップ遷移を一緒に確認。ユーザーの検索語・購入予定商品を分析ログへ送らない。
- **共有**：検索語・型番/JAN・検索側の予算条件のみURLに保持して共有。出品の時点別価格は記録しない。時間が経ったら再取得する。
- **商品トップ**：商品カードの「最安」を「今回の表示候補中で参考額が最小」とした。異なる商品の混在する一般検索結果を全市場最安と誤認させない。

## データソースと制約
- 楽天市場の公式 Ichiba Item Search API と、契約されている場合のみYahoo!ショッピング公式API。Yahoo!のAPIクライアントIDが無い場合はdisabledになり、商品価格を創作しない。
- Amazon、家電量販店などは検索リンクであり、実際の価格をAPIから取得できていない場合は一覧の最安値ランキングには含まれない。
- 送料、ポイント、クーポン、サービス手数料、端末割引、利用規約、発送予定日、販売店の信頼性はショップごとに異なる。
- 履歴データを保存していないため、価格推移グラフや値下がり通知を**実装済みとはしない**。欲しい場合は利用条件に適合する履歴保存と日時付きデータの継続的取得、ユーザー通知の許可が必要。
- 楽天の2026-04-01 APIは itemPrice, postageFlag, pointRate, affiliateUrl, reviewAverage, reviewCount を提供する。https://webservice.rakuten.co.jp/documentation/ichiba-item-search-20260401
- 価格.com公式ガイドでは価格履歴・最安お知らせが利用される。比較対象として参考にしたが、他社の画面や文章、データのコピーは行わない。https://support.kakaku.com/

## これから投資対効果を確かめること
1. 商品比較への訪問数、型番検索後の出品クリック数、4件比較の利用数を個人情報抜きで集計。
2. 楽天アフィリエイトの確定報酬を同期間で確認し、A8.net等の別媒体と混同せず評価。
3. 商品が一致しない検索、送料情報が得られない出品、画像読み込み失敗の頻度を調査。
4. 正規の追加モールAPI提携が可能なら、同一型番・同一条件の総額比較の精度を上げる。スクレイピングや第三者データの無断複製はしない。

## 2026-10-31 追加：支払見込額と目標価格メモ

### 購入直前の支払見込額（比較表内）
- 最大4件の出品に、**送料（税込）・実際に使えるクーポン額**を個別入力する。送料がAPIで「送料無料」と取得された場合のみ0円、その他の出品はユーザーが確認・入力するまで合計を出さない。
- 計算式：**商品価格 + 入力送料 − 入力クーポン**。ポイントは支払見込額から差し引かず、別の参考額として表示。広告紹介料は順位に一切含めない。
- 入力済みの候補だけで最小の試算額と差額を表示。入力値の空欄・負数・小数・超過クーポンは安全に扱い、誤って「無料」や「全店最安」としない。
- 入力した送料・クーポンはローカルの画面状態のみで、保存・分析イベント送信はしない。ショップ決済画面で税額・送料地域差・クーポン適用・在庫・返品等の最終確認が必要。

### 目標価格メモ（比較ページ下部）
- 現在の**検索語・JAN/型番・価格範囲・希望する商品価格**だけをブラウザーのlocalStorageに最大12件保存し、値段や商品画像などAPI返却情報を保存しない。
- **その検索結果を実際に取得した画面でだけ**、型番・JAN一致の根拠がある候補の最小**商品価格（送料別・ポイント差引前）**を目標額と比較。未照合の類似商品が安くても、到達とはしない。
- 自動クロール、サーバー監視、メール/プッシュ通知は実装していない。検索条件を再訪問して手動で確認する。端末間同期・会員データベースもない。
- 競合の「価格推移／値下がり通知」は将来検討事項。**現時点の機能に履歴グラフの名称を付けない**。

### 法的・品質上の理由
楽天ウェブサービスの公式ヘルプは、商品の**価格・販売可能情報の一般的なキャッシュ期間を24時間**とし、表示日時や更新頻度にも条件を定めている。価格の長期自動保存による履歴グラフを作る場合、別途の権利・データ取得手段を検証する必要がある。今回の目標価格メモは楽天やYahoo!の価格を保存しない。
