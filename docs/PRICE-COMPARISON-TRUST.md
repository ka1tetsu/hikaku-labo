# 商品価格とポイントの比較設計

## 表示と比較の基準
商品比較での標準順位は、**取得した出品の商品価格（ポイント差引前、送料別）**の安い順です。検索APIから得られた一部候補に限った比較で、全ショップ最安値や注文時の最終支払額を保証しません。

ユーザーが「ポイント考慮後の参考額」を選ぶと、付与予定ポイントを単純に差し引く順位に切り替えます。この数字は現金支払額ではありません。ポイントには利用条件、付与時期、上限・期限があり、取得元の条件が変わる場合があります。出品行では常に商品価格を主表示し、参考額を別表示します。

## 実装の分離
- `src/shared/priceCompare.js`: 商品照合・API提供データの正規化。既存のバックエンド処理を維持。
- `src/shared/offerDisplay.js`: フロントエンド上の順位と範囲。データを破壊せず、現金優先で表示。
- `src/compare/ComparePage.jsx`: 明示的な基準セレクター・注意事項・購入先確認へのリンク。
- `api/compare.js`: 上流検索の取得候補がポイント基準の途中打ち切りで欠けないよう、返却上限を40から80件へ変更（実際の取得件数は上流結果による）。APIキー・ASPのURL・計測処理は変更なし。

## 検証
`tests/offer-display.test.mjs` が金額順と参考額順の違い、欠損値、開示テキスト、API候補上限を検査します。Chromium QAの`cash-vs-points-shopping-order`は、架空の2出品をAPIモックしてスマホ上で順位切替と開示を検査します。テスト例の金額は本番の商品価格ではありません。
