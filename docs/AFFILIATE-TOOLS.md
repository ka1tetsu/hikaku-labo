# 比較ラボ / tools — 運用ガイド

## 新しい比較ツール

- URL: /tools/ （Viteマルチページビルド。商品比較トップページを壊さない）
- プラン比較: Web制作 / ネットショップ / WordPress の3カテゴリ・各2件
- 条件: 月額予算・重要視する機能。独自ルールによる再現可能な順位付け
- 参照元URL、注意事項、最低料金の適用条件、比較対象3件を表示
- スコアはAIモデルの予測確率ではありません。大量のLLM記事生成を実装したものでもありません
- 個人名、メールアドレスを診断のために集めません

## ローカル確認

npm ci
npm run test:tools
npm run lint
npm run build
npm run dev

/ と /tools/ をそれぞれ確認してください。

## 提携リンクを正しく有効化する

1. 広告主かASPに直接申し込み、サイト登録・利用規約と媒体審査を通します。
2. src/tools/affiliate.js の APPROVED_AFFILIATE_LINKS に、対象サービスIDごとに正式に発行された https の成果計測URLだけを登録します。
3. ローカルで実際の遷移先・rel=sponsored・適切な広告表示を確認し、公開ページの広告開示を維持します。
4. リンク未設定のサービスは通常の公式URLへ遷移し、紹介報酬が発生したとは扱いません。提携のないサービスもランキングから削除しません。

例（以下は使えないプレースホルダーです）:
shopify: 'https://YOUR_APPROVED_TRACKING_URL'

リンク用の認証トークン、非公開APIキー、ASPの管理用パスワードはコードに記載しないでください。

## 料金・広告ポリシー

- src/tools/catalog.js の価格を更新する際は必ず sourceUrl を確認し、サイト上の LAST_REVIEWED を更新します。
- 年払い月額換算、税込・税抜、決済手数料、契約期間の違いを隠しません。
- スコアリングの入力は用途、予算、優先事項のみです。広告の承認・コミッション率は順位に使いません。
- 法令に従って広告・PRを明示し、未確認の実績・体験談・「AIが100%最適化」等を捏造しません。
- 日本の景品表示法、ステルスマーケティング告示、Google検索スパムポリシーに配慮します。

## 最初の計測

api/track.js は公式/広告リンクへのクリックを構造化して Vercel Function Logs に出力する最小機能です。Cookieや個人情報は採取しません。このログだけでは広告主での成約や発生報酬は測れません。

- outbound（公式/広告クリック）
- ASP側の確定成果・承認率（各ASP管理画面）
- 診断開始/終了（現状未実装、専用分析基盤が必要）
- チャネル別流入（Search Console / 許可を得た分析基盤）

報酬はASP管理画面で実績を必ず確認し、推定クリック数だけを売上としないでください。
