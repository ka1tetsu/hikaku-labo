# 比較ラボ｜収益改善の運用手順（2026-10-17）

## 目的と現状

公開対象: /、/tools/、/travel/、/guides/travel-budget/、/guides/website-tools/。
現段階で使えるA8.net紹介素材は Yahoo!トラベルのみ（ユーザー提供済みの2件）。ITツール比較は承認済み成果リンク **0件** なので、ここからのA8.net報酬を主張しないこと。
楽天・Amazon・Yahoo!の商品ページ側は既存アフィリエイトIDを使うが、有効なアカウントかどうかと確定報酬は各ASPでしか確認できない。

## 変更済みのもの

1. 検索対象5ページのサイトマップ `/sitemap.xml` と `/robots.txt`。
2. 独自に執筆した、関連性のある2記事（旅行予算とWeb制作ツールの選び方）と、対象の無料計算機/診断へ行ける内部リンク。
3. 商品比較トップの「楽天」クイック検索を通常の楽天検索URLから **既存アフィリエイトID付き検索URL** に修正。楽天の利用資格は別途検証する。
4. サイト内の外部リンクのクリックを最小構成で計測（商品・IT・Yahoo!トラベル）。クリック前後のリダイレクトやA8.netの広告HTMLは変更していない。
5. GitHub Actionsで全ページとサイトマップの公開応答を週1回検査。テストと本番依存のセキュリティ監査も実施。

## ログで把握できること／できないこと

`/api/track` は Vercel Function Logs に `hikaku_view`（ページ・流入元の種類）と `hikaku_outbound`（`section` / `merchant` / `placement` / `sponsored`）を記録します。
Upstash Redis を接続すると、同じイベントが日別の合計値として保存され、`/admin/` で訪問者数・ページビュー・クリック率・成約率を確認できます（詳細は `docs/ANALYTICS.md`）。
端末ID、Cookie、個人名、検索キーワード、商品名、広告URL、参照元URLは送信・保存しません。
`outbound` は広告主への送客候補の操作で、広告主が認識したクリック数や実際の売上・確定報酬とは異なります。
成果件数・報酬は ASP の管理画面の数字を `/admin/` に入力（またはポストバック）したもので、確定報酬は必ず ASP 側で確認してください。

## 収益KPI（必ずASPの実データから）

- **発生成果件数**: A8.net「レポート」などで期間を揃えて取得。
- **確定報酬（円）**: 否認・キャンセル後に承認された報酬。未確定の成果を収益として計上しない。
- **サイト運営コスト（円）**: Vercel請求書、ドメイン、API、その他の実額。
- **暫定的な利益（円）**: 確定報酬合計 - 実際の運営コスト（税・人件費等は別管理）。
- **広告素材別分析**: Yahoo!トラベルの素材ID 035 と034に対応するクリック・成果をA8.netで比較。サイト側の `banner234` / `banner300` ログと単純に同一視しない。

広告枠の成果が改善しても、元の広告HTML、テキスト、バナーサイズ、計測画像を無断変更しないこと。
A8.netの規約は原文素材をそのまま使うよう要求します。
公式: https://support.a8.net/a8/as/faq/2025/post_2598.html

## これから必要な本人操作（サイト側コードでは完了できない）

1. [Google Search Console](https://search.google.com/search-console/) で `https://hikaku-labo.vercel.app/` の所有権を確認し、`https://hikaku-labo.vercel.app/sitemap.xml` を送信。サイトマップはクロールの参考であり、検索順位や流入数を保証しません。
2. A8.net「広告掲載URL管理」で少なくとも `https://hikaku-labo.vercel.app/travel/` を申告し、各広告主の掲載条件や提携継続を確認。
3. A8.netのYahoo!トラベル案件で「素材035」「素材034」の広告クリック・発生成果・確定成果を時系列で観察。**自分でアフィリエイトリンクを連打・自己クリックしない**。
4. [A8.net](https://www.a8.net/)でEC作成ツールやレンタルサーバーなど、/tools/で既に紹介しているサービスに対応する案件を探し、提携申請。承認前のトラッキングURLや報酬は絶対に捏造しない。
5. 本人がA8.netの「通常広告用」コードを取得し、`src/tools/a8Placements.js` の適切なサービスIDに原文全文のまま設定する。
6. Vercelで現状権限403が確認されている場合は `ka1tetsus-projects` チームへの連携権限を復旧し、ログ・請求額・本番エラーを確認する。トークンやパスワードをChatGPTの会話に貼り付けない。

## 週次の判断サイクル

- まずASPの実際の確定報酬と運営費を確認する。
- GSCで検索クエリ/検索流入/インデックスを確認する（推測しない）。
- Vercelログの `merchant`、`placement` 別クリック数を集計する。
- 閲覧に対してクリックが低ければ、広告の改変ではなく **説明文・比較の根拠・文脈に合う導線** を改善する。
- 成果が薄ければ、承認済み案件の利用条件・読者との適合性を確認する。
- 重要な公開情報を見直す場合は一次情報から確認し、料金の見直し日を更新する。

Googleの「役に立つ、ユーザー第一のコンテンツ」方針に従い、根拠の薄い大量のSEOページ生成や存在しないランキング/口コミの創作をしない。
公式: https://developers.google.com/search/docs/fundamentals/creating-helpful-content
