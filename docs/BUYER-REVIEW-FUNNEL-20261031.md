## 公式データの合法な扱い
- [Yahoo!ショッピング商品検索 API v3](https://developer.yahoo.co.jp/webapi/shopping/v3/itemsearch.html) の `hits.review.rate` / `hits.review.count` / `hits.review.url` と `hits.seller.review.rate` / `hits.seller.review.count` は商品と店の異なる指標。価格、在庫、JANと併せて同じ検索レスポンスの出品ごとに保持。レビュー本文を取得・保存・転載せず、取得元公式URLにだけリンク。
- [楽天商品検索API](https://webservice.rakuten.co.jp/documentation/ichiba-item-search) の集計値は認証が正常になった場合のみ表示。2026-10-31本番では楽天403が継続し得るため、未取得表示を維持する。
- [Amazonアソシエイト規約](https://affiliate.amazon.co.jp/help/operating/policies) はCreators APIライセンスの例外を除きAmazonの星評価・レビュー転載を制限。承認を確認できない状態ではAmazon検索を開く導線に限定し、数値や原文は表示しない。
- 他の口コミサイトの独自投稿やレビュー本文をGoogle検索結果から自動収集しない。自社の体験談・レビュー投稿募集は投稿者の同意、誹謗中傷対応、景品表示法・ステルスマーケティング告示対応の別プロジェクトとする。

## 順位基準と透明性
`src/shared/buyingDecisionCandidates.js` の選出は取引元別の出品価格・送料・評価のみを利用し、広告成果や会員ポイントの予測は使用しない。
- **価格重視**：照合済み・在庫なしと判明していない・送料0円表示の出品の最小**商品価格**。全国最安や購入時支払総額の保証ではない。
- **商品口コミ重視**：同一商品照合済み＋有効な商品口コミが20件以上。件数補正付き平均点の参考順位。原文の悪評・修理や保証を必ず確認。
- **販売店評価重視**：同一商品照合済み＋有効な店舗口コミが20件以上。店の対応評価は製品の性能保証ではない。
- 同一出品が複数の条件に当てはまる場合も、無理に別店を推薦しない。
- クリックで本人の比較候補に追加すると元の出品URLとショップをそのまま保持。評価が異なる出品の平均を捏造しない。比較は最大4件。

## 実測可能性
- 匿名・cookie-freeの `outbound` イベントで `review-source`（公式口コミページ閲覧）、`review-seller`（販売店情報）、`review-source-row`（商品詳細行の出典）、`reason-outbound`（目的別購入先リンク）を区別。ブラウザ/利用者を結びつけるID、検索語、レビュー内容、価格、商品URLを送らない。
- `product_offer_selected` と販売先クリックを**個人の経路として結びつけて追跡**はしない。サイト全体の集計レベルで離脱の大きい段階を改善。アフィリエイト売上はASPの確定実績でのみ認定。
- 最新本番デプロイの SHA を別途確認。GitHub CI成功だけを「本番公開済み」と表記しない。Hobby枠のデプロイ回数制限に留意。
